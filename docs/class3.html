Session 3A: Content

The Story So Far

::: {style=”font-size: 1.8em; line-height: 2;”} - Class 1: You found the walls. - Class 2: You broke through and found… nothing. - Class 3: So what? What does this mean for how you use AI? :::

::: {style=”font-size: 2em; margin-top: 40px;”} Just patterns. :::

The Convergence Problem

::: {style=”font-size: 2em; line-height: 1.8;”} AI outputs are not “original.”

They are the statistical average of training data. :::

::: {style=”font-size: 2.5em; font-weight: bold; color: #c0392b;”} Every output is the most likely next token, :::

::: {style=”font-size: 2.5em; font-weight: bold; color: #c0392b; margin-top: 20px;”} repeated. :::

::: {style=”font-size: 1.8em; line-height: 1.8;”} When you accept defaults, you are accepting the average of everything that came before. :::

::: {style=”font-size: 2em; font-weight: bold; color: #e67e22; margin-top: 40px;”} You are sliding into a groove worn by millions of previous users. :::

The Real Danger

::: {style=”font-size: 2em; line-height: 1.8;”} The legal risks are real.

The ethical risks are real. :::

::: {style=”font-size: 1.8em; margin-top: 40px; color: #7f8c8d;”} But there’s a fourth risk nobody talks about: :::

::: {style=”font-size: 3em; font-weight: bold; color: #c0392b;”} Creative Risk: :::

::: {style=”font-size: 3.5em; font-weight: bold; color: #8e44ad; margin-top: 30px;”} You vanish into the mean. :::

The Questions

::: {style=”font-size: 1.8em; line-height: 2; margin-top: 30px;”} - If everyone uses the same tools trained on the same data, what happens to range?

  • Does the space of human creative output expand or contract?

  • When you use AI unreflectively, are you creating—or just retrieving? :::

Charter Questions

::: {style=”font-size: 1.8em; line-height: 1.8;”} Your charter must address: :::

::: {style=”font-size: 1.6em; line-height: 2; margin-top: 20px;”} - What’s allowed? (green light) - What’s slowed down? (yellow — needs review) - What’s stopped? (red line) - Who decides edge cases? - What happens when it breaks? :::

::: {style=”font-size: 1.8em; line-height: 2;”} Display your charter. Circulate and vote on:
