split_pairs#

split_pairs(pairs, train_ratio=0.85, random_seed=42)[source]#

Shuffle image pairs reproducibly and split them into two lists.

Parameters:

  • pairs (List[Tuple]) – Image-pair records such as those returned by collect_image_pairs().

  • train_ratio (float) – Fraction assigned to the training list.

  • random_seed (int) – Seed used for the local split order.

Returns:

The training pairs followed by the remaining test pairs.

Return type:

Tuple[List, List]
